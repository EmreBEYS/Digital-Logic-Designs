# Digital Logic Designs

This repository contains circuit designs created as part of Digital Logic Design coursework and personal practice.

## Projects

### 01 - Number Systems and Converters

This section contains circuits related to number systems, digital encoding, and code conversion.

#### BCD to 7-Segment

A digital circuit that converts a BCD input into the corresponding output required by a seven-segment display.

Topics covered:

- Binary Coded Decimal
- Seven-segment displays
- Combinational logic
- Digital encoding
- Logic gates

#### Octal to Binary

A circuit designed to demonstrate conversion between octal and binary representations.

Topics covered:

- Number systems
- Binary representation
- Octal representation
- Digital conversion logic
